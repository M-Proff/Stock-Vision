
# Stock Vision

A stock market dashboard project integrating backend and frontend with MongoDB Atlas and React.  

## Project Status
- Backend connected to MongoDB Atlas and running locally.
- Frontend dashboard partially implemented.
- Work in progress towards full deployment and additional features.

## Getting Started

1. Clone the repository.
2. Install dependencies in both `backend` and `frontend` folders using `npm install`.
3. Set up your `.env` file with your MongoDB connection URI and other configurations.
4. Run the backend server:
   ```bash
   npm start
